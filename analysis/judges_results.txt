====================================================================
 EMBER PHASE 2: RESULTS FOR JUDGES
====================================================================

 All analyses use leave-one-subject-out cross-validation on
 PROSPIE V3 (chest heart-rate sensors only, 6 conformal strata,
 the same calibration as firmware/ember/conformal_table.h).

 37 subjects, 14041 scored minutes, 128 trials

====================================================================
 1. COVERAGE: Kalman posterior variance vs conformal
====================================================================

  90% nominal interval coverage:
    Kalman posterior:      34.3%  (mean width 0.34 °C)
    Conformal calibrated:  89.7%  (mean width 1.34 °C)

  Headline: Kalman's "90%" interval covered 34.3% of true values.
            Conformal's 90% interval covered 89.7%.

====================================================================
 2. COVERAGE BY TRUE TEMPERATURE BAND
====================================================================

                  Band      n   Kalman  Conformal
  ------------------------------------------------
        normal (<37.5)   3949    0.357      0.981
      warm (37.5-38.0)   4435    0.404      0.953
     watch (38.0-38.5)   3783    0.309      0.856
       act now (≥38.5)   1874    0.242      0.669  <- under 85%

  The Kalman interval fails most where it matters most: at high core temps.
  Conformal is calibrated by PREDICTED temperature, so coverage conditional
  on TRUE temperature is not guaranteed; it drops at >=38.5 because the
  estimate lags and reads low when core is high.

====================================================================
 3. ALERT TIMING: when true core first reached 38.5°C
====================================================================

  73 trials where true core reached 38.5°C

  Watch (estimate >= 38.0°C):
    already on at that minute:  47 / 73 (64%)   [on beforehand: 45]
      had been on for: median 13 min (IQR 6-21)
    came on later:              21 / 73, median 14 min late, worst 65 min
    never came on:              5 / 73 (7%)
    lag (0 if already on):      median 0 min, worst 65 min (among 68 that fired)
    [secondary] first on anywhere in trial: median -9 min relative to true 38.5

  Act now (estimate >= 38.5°C):
    already on at that minute:  18 / 73 (25%)   [on beforehand: 17]
      had been on for: median 8 min (IQR 5-11)
    came on later:              21 / 73, median 41 min late, worst 63 min
    never came on:              34 / 73 (47%)
    lag (0 if already on):      median 1 min, worst 63 min (among 39 that fired)
    [secondary] first on anywhere in trial: median +1 min relative to true 38.5

  Watch came on but Act now never did: 29 / 73 (40%)
  Neither alert ever came on:          5 / 73 (7%)

  Watch carries the safety load: it is already on in most trials when
  true core reaches 38.5, while Act now is usually late or never fires.

 4. SEX BIAS ANALYSIS
====================================================================

  F:  n_subjects=15,  n_samples=5574
    bias: -0.087 °C
    RMSE: 0.418 °C
    90% conformal coverage: 88.1%

  M:  n_subjects=20,  n_samples=7963
    bias: -0.182 °C
    RMSE: 0.400 °C
    90% conformal coverage: 90.1%

  Bootstrap analysis of BIAS difference (5000 resamples of subjects):
    M minus F: -0.095 °C
    95% CI: [-0.262, +0.093]  (includes zero)
    P(difference > 0): 0.152

  Bootstrap analysis of RMSE difference (for comparison):
    M minus F: -0.018 °C
    95% CI: [-0.126, +0.086]  (includes zero)

  Note: Bias is the primary metric. A systematic offset between groups
        moves bias substantially but barely affects RMSE (which is dominated
        by within-subject variation). See evaluate.py comments for details.

====================================================================
 5. COVERAGE: Rising vs Steady (OPTIONAL)
====================================================================

  Rising phase (Δcore ≥ +0.2°C in 5 min):  n = 1253
  Steady phase (|Δcore| < 0.1°C in 5 min):  n = 6416

  Rising:
    Kalman 90%:     30.5%
    Conformal 90%:  84.9%

  Steady:
    Kalman 90%:     32.7%
    Conformal 90%:  90.8%

  Rising coverage is under 85%: consider stratifying the calibration
  by rising/steady as well as by predicted temperature.

====================================================================
 6. PULSE SENSORS: does the chest calibration hold for optical HR?
====================================================================

  Finger PPG appears only in conditions [1, 2, 3]. Chest table, leave-one-subject-out:
  finger pulse trials                 28 trials  bias -0.41  coverage 74.4%  HR missing 80%
  chest trials, same conditions       25 trials  bias -0.36  coverage 77.9%  HR missing 79%

  Most of the gap is the conditions (heart rate missing in most
  minutes in both groups), not the sensor. Same conditions, pulse vs
  chest differ by -0.05 °C bias and -3.5 points of coverage.
  The filter only sees heart rate: if Ember's pulse sensors report the
  same heart rate as a chest strap, the chest calibration applies.
