====================================================================
 EMBER PHASE 2: RESULTS FOR JUDGES
====================================================================

 All analyses use leave-one-subject-out cross-validation on
 PROSPIE V3 (chest heart-rate sensors only, 6 conformal strata,
 the same calibration as firmware/ember/conformal_table.h).

 37 subjects, 14041 scored minutes, 128 trials

====================================================================
 1. COVERAGE: Kalman posterior variance vs conformal
====================================================================

  90% nominal interval coverage:
    Kalman posterior:      34.3%  (mean width 0.34 °C)
    Conformal calibrated:  89.2%  (mean width 0.99 °C)

  Headline: Kalman's "90%" interval covered 34.3% of true values.
            Conformal's 90% interval covered 89.2%.

====================================================================
 2. COVERAGE BY TRUE TEMPERATURE BAND
====================================================================

                  Band      n   Kalman  Conformal
  ------------------------------------------------
        normal (<37.5)   3949    0.357      0.890
      warm (37.5-38.0)   4435    0.404      0.956
     watch (38.0-38.5)   3783    0.309      0.907
       act now (≥38.5)   1874    0.242      0.712  <- under 85%

  The Kalman interval fails most where it matters most: at high core temps.
  Conformal is calibrated by PREDICTED temperature, so coverage conditional
  on TRUE temperature is not guaranteed; it drops at >=38.5 because the
  estimate lags and reads low when core is high.

====================================================================
 3. ALERT TIMING: when true core first reached 38.5°C
====================================================================

  73 trials where true core reached 38.5°C

  Watch (estimate >= 38.0°C):
    already on at that minute:  65 / 73 (89%)   [on beforehand: 61]
      had been on for: median 12 min (IQR 5-19)
    came on later:              8 / 73, median 8 min late, worst 41 min
    never came on:              0 / 73 (0%)
    lag (0 if already on):      median 0 min, worst 41 min (among 73 that fired)
    [secondary] first on anywhere in trial: median -12 min relative to true 38.5

  Act now (estimate >= 38.5°C):
    already on at that minute:  17 / 73 (23%)   [on beforehand: 16]
      had been on for: median 4 min (IQR 2-11)
    came on later:              29 / 73, median 15 min late, worst 62 min
    never came on:              27 / 73 (37%)
    lag (0 if already on):      median 4 min, worst 62 min (among 46 that fired)
    [secondary] first on anywhere in trial: median +4 min relative to true 38.5

  Watch came on but Act now never did: 27 / 73 (37%)
  Neither alert ever came on:          0 / 73 (0%)

  Watch carries the safety load: it is already on in most trials when
  true core reaches 38.5, while Act now is usually late or never fires.

====================================================================
 6. PULSE SENSORS: does the chest calibration hold for optical HR?
====================================================================

  Finger PPG appears only in conditions [1, 2, 3]. Chest table, leave-one-subject-out:
  finger pulse trials                 28 trials  bias -0.12  coverage 85.4%  HR missing 80%
  chest trials, same conditions       25 trials  bias -0.11  coverage 79.7%  HR missing 79%

  Most of the gap is the conditions (heart rate missing in most
  minutes in both groups), not the sensor. Same conditions, pulse vs
  chest differ by -0.01 °C bias and +5.6 points of coverage.
  The filter only sees heart rate: if Ember's pulse sensors report the
  same heart rate as a chest strap, the chest calibration applies.
